# 八种视觉风格 + 沿用产品 UI

所有年龄使用相同信息颗粒度。风格改变字体、配色、构图、表面和图形语言，不改变文案、事实、论据数量或逻辑深度。

## 选择

优先复用已确认的 style_id。首次制作展示 [可视化风格画廊](../assets/style-gallery.html)：8种预设和第9项「沿用产品 UI」。每个预设可看方案与TAM两个同内容示例，不只给抽象名称；学生可以直接回复编号或名称，也可以复制画廊生成的一句话请求。画廊选择只保存在浏览器用于复制，不自动写项目设置；执行Skill时才写项目的 `_working/pitch-settings.json`。允许自定义或沿用已有风格；不要求再选一遍。

## 八种预设

### 1. 编辑部白 · `studio-editorial-white`
- 适合：干净、清晰的现代产品路演
- 设计语言：无衬线标题、轻边框、均衡网格、克制阴影
- 取舍：避免无意义大留白和整页卡片堆叠

### 2. 午夜发布会 · `midnight-product-launch`
- 适合：深色舞台，突出产品与关键数字
- 设计语言：深色背景、产品主视觉、亮色焦点、留出呼吸感
- 取舍：避免霓虹光晕、通篇发光边框和灰字难读

### 3. 未来实验室 · `future-lab`
- 适合：有秩序的科技感，突出过程与证据
- 设计语言：细线网格、小半径、标注与明确连接、清楚状态
- 取舍：避免假代码、装饰性技术仪表和复杂架构

### 4. 瑞士网格 · `swiss-grid`
- 适合：强对齐、清楚层级、利落的编辑设计
- 设计语言：硬朗网格、少量红色强调、直角、粗细字体对比
- 取舍：避免把所有字都加粗或把红色铺满页面

### 5. 暖调杂志 · `warm-editorial`
- 适合：温润、精致，适合生活与人文产品
- 设计语言：克制衬线标题、纸感暖白、细线、图文编辑关系
- 取舍：避免复古花纹、手写贴纸、棕色低对比文字

### 6. 自然工作室 · `botanical-studio`
- 适合：安静、可信，适合健康与可持续主题
- 设计语言：柔和墨绿、舒展间距、圆润轮廓、统一细线图形
- 取舍：避免卡通叶片、装饰植物抢戏和无意义绿色

### 7. 钴蓝展厅 · `cobalt-gallery`
- 适合：鲜明、有力量，突出产品主张
- 设计语言：钴蓝大色面、暖白或浅金重点、简洁几何构图
- 取舍：避免高饱和色混用和海报化到无法承载论据

### 8. 黑白精工 · `monochrome-minimal`
- 适合：理性、克制，突出文字与产品本身
- 设计语言：黑白灰、精确网格、细分隔线、字重与尺寸对比
- 取舍：避免只剩大字和空白，灰度也要有重点

## 9. 沿用产品 UI · `product-ui`

按 [产品风格提取](product-style.md) 读取当前整个项目的设计相关文件与实际画面，生成专属视觉约定和预览。通用画廊第9项只说明流程，不能冒充已经分析了该产品。

## 落地与质量

颜色、字体、圆角与阴影的初始参数在 [style-presets.json](../assets/style-presets.json)，可复用 [pitch-themes.css](../assets/pitch-themes.css)。参数是起点，还需按各风格的构图与字重说明完成设计，不能只换主色。将最终所用CSS内嵌到HTML，不引入联网资源。

继承模板的画布、翻页和语义结构；原模板的部件可能仍用默认色，选择其他风格时检查每个深浅背景上的文字、边框和图表，不能仅切换一个主题变量就交付。按 [视觉完成度](visual-finish.md) 渲染封面、方案与TAM代表页，再检查全六页。

旧的三个ID仍有效，不强制重新选择。未知旧ID保留原值于 legacy_style_id，并按custom处理。设置最少记录 style_id、style_name、统一颗粒度；product-ui另外记录实际产品风格文件路径和来源。
